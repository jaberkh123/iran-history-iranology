# دانشنامه‌ی تاریخ و ایران‌شناسی ایران

مجموعه‌ی بخش‌بخش‌شده از مخازن گیت‌هاب و منابع مرجع — آماده‌ی ارسال قطعه‌قطعه به API.

این مخزن یک بانک دانش آماده‌ی ماشین است: محتوا از بازخوانی مخازن تاریخ و ایران‌شناسی گیت‌هاب (بیست‌ویک مخزن اصلی + پنج مخزن مجاور) و راستی‌آزمایی با منابع مرجع ساخته شده و به‌صورت 36 بخش مستقل با سقف ۱٬۰۰۰ واژه در هر بخش سازمان یافته است — یعنی هر بخش می‌تواند به‌تنهایی به یک API یا مدل زبانی داده شود.

## چگونه بخش‌ها را جدا کنیم؟

هر بخش در فایل جامع میان دو نشانه است:

```
<!-- SECTION id="s024" file="sections/s024-nader-shah.md" ... -->
## بخش ۲۴ — نادرشاه افشار؛ از خراسان تا کرنال و تخت طاووس
...
<!-- /SECTION s024 -->
```

جداسازی با پایتون:

```python
import re
text = open("iran-history-iranology.md", encoding="utf-8").read()
pattern = r"<!-- SECTION id=\"(s\d+)\".*?-->\n\n(.*?)\n\n<!-- /SECTION \1 -->"
sections = {sid: body for sid, body in re.findall(pattern, text, flags=re.S)}
print(len(sections), "بخش")
```

یا ساده‌تر: فایل تکی هر بخش را مستقیم از `sections/` بخوانید.
