## بخش ۰۷ — تقویم جلالی در دنیای نرم‌افزار؛ و مجوزهای قانونی این منابع

مخزن `jalaali/moment-jalaali` (۹۷۵ ستاره) پلاگین تقویم جلالی برای کتابخانه‌ی moment.js است و README آن عملاً یک درس کوچک گاه‌شماری ایرانی است. سه چیز مهم در آن هست: نخست تعریف کوتاه — «تقویم جلالی یک تقویم خورشیدی است که در ایران به‌کار می‌رفت و گونه‌هایش امروز هم در ایران و افغانستان رسمی است». دوم مرجع الگوریتم: تبدیل تاریخ بر پایه الگوریتم کازیمیر م. بورکوفسکی انجام می‌شود؛ یعنی ریاضیاتِ کبیسه‌ی ۳۳ساله که در بخش ۳۰ این مجموعه باز می‌شود. سوم و مهم‌تر، یک یادداشت فنی تکان‌دهنده از فوریه ۲۰۲۲: اگر فقط می‌خواهید تاریخ را نمایش دهید، لازم نیست هیچ کتابخانه‌ای نصب کنید؛ مرورگرها با استاندارد `Intl` خودشان تقویم فارسی را می‌سازند — نمونه‌ی رسمی مخزن نشان می‌دهد که `new Intl.DateTimeFormat('fa-IR')` برای تاریخ میلادی ۲۱ مارس ۲۰۲۲ همان «۱۴۰۱ فروردین ۱، دوشنبه» را چاپ می‌کند و حتی حالت انگلیسیِ تقویم‌فارسی با `en-US-u-ca-persian` ممکن است.

> **نکتهٔ نغز —** در خود README، نمونه‌ی اعتبارسنجی کبیسه هست: تاریخ «۱۳۹۱/۱۲/۳۰» معتبر است چون سال ۱۳۹۱ کبیسه بود و اسفندش سی روز داشت؛ اما «۱۳۹۲/۱۲/۳۰» نامعتبر است چون اسفند ۱۳۹۲ فقط بیست‌ونه روز داشت. یعنی «سی‌ام اسفند» به‌طور متوسط فقط هر چهار سال یک‌بار وجود دارد — یک تست نرم‌افزاری عالی برای هر API تاریخ‌محور فارسی.

در اکوسیستم فرهنگی گیت‌هاب (که در گزارش قبلی تفصیل دادیم)، این تقویم پرستاره‌ترین حوزه فارسی است: `Kiarash-Z/react-modern-calendar-datepicker` با ۱٬۰۳۹ ستاره، `persian-calendar/persian-calendar` اپ اندروید با ۹۹۵ ستاره، `omid/Persian-Calendar-for-Gnome-Shell` با ۵۶۶ ستاره و `hekmatinasser/verta` PHP با ۶۶۳ ستاره. نتیجه برای پروژه‌ی شما: اگر محتوا به تاریخ خورشیدی نیاز دارد، الگوریتم بی‌نقص و آزموده در دسترس است و بخش «گاه‌شماری» بانک دانش شما پشتوانه‌ی فنی دارد.

دست دوم این بخش، جدول مجوزهای قانونی است؛ برای ارسال چانک‌ها به API و بازنشر، این‌ها را حتماً رعایت کنید:

| منبع / مخزن | مجوز | اجازه‌ی استفاده |
| --- | --- | --- |
| silk-road (کتاب جاده ابریشم) | CC BY 4.0 | بازنشر و اقتباس حتی تجاری، با انتساب |
| Old-Persian-Dataset و Old-Persian-Cuneiform-OCR | CC BY-NC | فقط غیرتجاری؛ استفاده تجاری ممنوع |
| متادیتای موزه مت (MetObjects) | CC0 | آزاد کامل؛ اجباری نیست ولی انتساب پسندیده است |
| سلاطین دکن فارسی | آموزشی/غیرتجاری | فقط پژوهشی؛ حقوق اصلی با موزه مت است |
| دیتاست شاهنامه، اطلس‌ها و تایم‌لاین‌ها | معمولاً بدون لایسنس | پیش‌فرض حق مؤلف؛ برای استفاده نویسنده را مطلع کنید |
| متن اوستا (avesta.org) | میراث عمومی (ترجمه ۱۸۹۸) | آزاد |

دو قاعده‌ی عملی هم بگذارید: نخست، تعداد ستاره‌ها و وضعیت مخزن‌ها در تاریخ گردآوری ثبت شده و ممکن است تغییر کند؛ اگر پروژه‌ای برایتان حیاتی شد، فورک یا آرشیواش کنید. دوم، برای استناد در تولید محتوا، الگوی پیشنهادی «نام مخزن (نویسنده، سال دسترسی) + لینک» است؛ نمونه: «ایرانشهر — اطلس سه‌بعدی تاریخ ایران (mhdvi، بازبینی ۲۰۲۶)». با این الگو هر چانک خروجی API شما، ردِ منبعش را هم می‌تواند داشته باشد.
